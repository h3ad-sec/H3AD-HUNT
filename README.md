# H3AD-HUNT

**Threat Hunting Hub — Part of [H3AD-SEC](https://h3ad-sec.github.io)**

H3AD-HUNT is the threat hunting module of the H3AD-SEC platform. It provides tools for hypothesis-driven hunting, investigation pivoting, and threat-specific query packs.

Live at: [h3ad-sec.github.io/H3AD-HUNT](https://h3ad-sec.github.io/H3AD-HUNT/)

---

## Tools

### [HYPOS](https://h3ad-sec.github.io/HYPOS/)
A hypothesis-driven threat hunting platform built on MITRE ATT&CK. Generates structured hunting hypotheses from STIX data, supplemented with curated content including detection logic, pivot points, threat actor context, and mitigations. ATT&CK matrix view on load.

### [PIVEX](https://h3ad-sec.github.io/PIVEX/)
An interactive force-directed graph mapping how to pivot across 36 artifact types during a security investigation. Build investigation chains, view MITRE technique tags per artifact, and export pivot paths as CSV or text.

### [TRACEPULSE](https://h3ad-sec.github.io/TRACEPULSE/)
Threat-specific query packs tied to active campaigns, threat actors, and CVEs. Covers KQL, Sigma, and XQL platforms. Search by threat name or CVE identifier.
